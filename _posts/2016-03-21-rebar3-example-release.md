Using rebar3 is now the industry standard for building and dependency management when programming Erlang. This comes as a result of rebar3 becoming an official part of the Erlang ecosystem.

Rebar3 provides a comprehensive solution for:
- Managing dependencies
- Building projects
- Running tests
- Generating documentation
- Creating releases

The tool has evolved significantly since its early versions and now offers a much more robust and user-friendly experience for Erlang developers.
